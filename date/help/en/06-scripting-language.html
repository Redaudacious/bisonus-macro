Scripting language

Each macro is a short script. The language looks like AutoHotkey v2. The program checks the script while you type. A macro with an error stays gray in the panel and shows the line of the error.

Open the script of a macro in two ways:

  • In the main window, select the macro and click "Edit...".
  • In the panel, click the code button at the right of the row. Click "Save" to keep your changes.

A first example

key("4")
wait(2000)
block {
    key("/")
    text("Snow 2")
    key("Return")
}

The script presses 4 and waits 2 seconds. Then it blocks your keyboard, presses /, types "Snow 2" and presses Enter. Then it unblocks your keyboard.

Key names: the letters a to z, the digits 0 to 9, F1 to F12, Return, Space, Tab, Escape, BackSpace, Delete, Insert, Home, End, PgUp, PgDown, Up, Down, Left, Right, and the signs on the US keyboard. Put Ctrl+, Shift+ or Alt+ before a key for a combination.

Variables and values

A variable gets a value with :=. A value is a number or a text. A text is between double quotes.

count := 3
place := "Snow 2"
count += 1
place .= " now"

A variable without a value is an empty text. In a calculation, an empty text is 0. The names do not care about capital letters: Count and count are the same variable.

Two variables come from the program:

  • name is the name of the macro. A shared template writes the name of each macro with text(name).
  • A_Index counts the passes of the nearest loop, from 1.

In a text, `n is a new line, `t is a tab, `" is a double quote and `` is the sign ` itself.

Use := to set a variable. A line like x = 5 is an error, because = compares.

Control

if count = 1 {
    key("a")
} else if count = 2 {
    key("b")
} else {
    key("c")
}

while count < 10 {
    count += 1
}

loop 3 {
    text("pass " . A_Index)
}

loop {
    if A_Index > 5 {
        break
    }
}

Again:
key("a")
goto Again
  • The braces { } are necessary after if, else, while, loop and block.
  • break leaves the loop. continue goes to the next pass.
  • goto jumps to a label. A label is a name with a colon, on its own line, outside all braces.
  • return ends the script.
  • A comment starts with ; at the start of a line or after a space. /* … */ on its own lines is a comment too.

Blocking your keyboard

block { } blocks your keyboards while it runs. Your own keys do not mix with the keys of the macro. At the end of the block, your keyboards work again.

A block must end soon, so these are errors inside block { }: while, loop, goto, a label, break, continue, return, another block, and a wait() longer than 10000 ms. Put the loop outside, and use one block for each pass.

Your mouse works inside a block.

Stopping a macro

A macro stops at any time, also in a loop without end. Four ways stop it:

  1. the "■ Stop" button in the bar of the panel
  2. "Stop macro" in the menu of the tray icon
  3. the global key "Stop macro", Pause by default; change it on the page Keys
  4. the global key of the running macro, pressed a second time

Inside block { }, only the first two work, because your keyboard is blocked. When a macro stops, it releases the keys that keydown() holds, and it unblocks your keyboard.

The mouse

The coordinates are the coordinates of the desktop, in the units of KDE, from the top left corner of the first screen. AutoHotkey counts from the active window: here the count starts at the desktop. With two screens, the program was tested on one screen only. A point outside the screen stops the macro.

KDE must give the mouse to the program. If KDE gave only the keyboard, a mouse command stops the macro, and the status line of the panel shows the reason.

After the update to 0.7.0, KDE asks once more for access, because the program now asks for the mouse too. Accept the window.

Errors

Under the script, a line shows "✓ No errors" or the first error, with its line and column. The line of the error has a wavy underline. "Save" keeps a script with an error too, so you do not lose your work. The macro stays gray until you correct it.

An error while the macro runs, for example a division by zero, stops the macro. The status line of the panel shows the reason.

Not in this version

Your own functions, lists, WinActivate, KeyWait, ImageSearch, MsgBox and global keys written in the script are not in the language.
