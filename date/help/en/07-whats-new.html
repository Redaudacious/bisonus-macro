What's new

This page lists the changes of each version. The same list shows once in a small window after an update.

Version 0.7.0

New

  • Each macro is now a short script. The language has variables, loops, if, wait, keydelay and text. See the page Scripting language.
  • The script editor colors the words and underlines the line of the first error.
  • Macros made of old JSON steps change into scripts on the first start. The program keeps a copy of your old file.
  • Macros can click and move the mouse, with click, mousemove and wheel. KDE asks you once to allow the keyboard and the mouse.
  • You can stop a running macro in four ways: "Stop" in the panel, Pause, "Stop macro" in the tray menu, or the key of the macro again.
  • The package starts with no macros. The Bloodlines tree is a template.
  • At start, the program tells you what is missing from your session.
  • "bisonus-macro --cleanup" removes the KWin rule, the KWin scripts and the global keys.
  • A package for Arch Linux and CachyOS.
  • The description of the program shows in the language of your system.

Fixed

  • The panel keeps its scroll position when you collapse or expand a category.
  • "Apply" in the settings keeps the scroll position, the selected row and the collapsed branches of the Macros page.
  • A script with a very deep expression, a comment that does not end, or "nan" or "inf" as a number now gives an error.
