Limbajul de scripting

Fiecare macro e un script scurt. Limbajul seamănă cu AutoHotkey v2. Programul verifică scriptul cât scrii. Un macro cu o greșeală rămâne gri în panou și arată rândul greșelii.

Deschide scriptul unui macro în două feluri:

  • În fereastra principală, alege macro-ul și fă clic pe „Edit...”.
  • În panou, fă clic pe butonul codului, la dreapta rândului. Fă clic pe „Save” ca să păstrezi schimbările.

Un prim exemplu

key("4")
wait(2000)
block {
    key("/")
    text("Snow 2")
    key("Return")
}

Scriptul apasă 4 și așteaptă 2 secunde. Apoi blochează tastatura ta, apasă /, scrie „Snow 2” și apasă Enter. Apoi deblochează tastatura ta.

Variabilele și valorile

O variabilă primește o valoare cu :=. O valoare e un număr sau un text. Un text stă între ghilimele duble.

count := 3
place := "Snow 2"
count += 1
place .= " now"

O variabilă fără valoare e un text gol. Într-un calcul, un text gol e 0. Numele nu țin cont de literele mari: Count și count sunt aceeași variabilă.

Două variabile vin de la program:

  • name e numele macro-ului. Un șablon comun scrie numele fiecărui macro cu text(name).
  • A_Index numără trecerile celei mai apropiate bucle, de la 1.

Într-un text, `n e rând nou, `t e tab, `" e ghilimea dublă și `` e semnul ` însuși.

Controlul

if count = 1 {
    key("a")
} else if count = 2 {
    key("b")
} else {
    key("c")
}

while count < 10 {
    count += 1
}

loop 3 {

loop {
    if A_Index > 5 {
        break
    }

  • Acoladele { } sunt obligatorii după if, else, while, loop și block.
  • break iese din buclă. continue trece la pasul următor al buclei.
  • goto sare la o etichetă. O etichetă e un nume cu două puncte, pe rândul ei, în afara oricărei acolade.
  • return încheie scriptul.
  • Un comentariu începe cu ; la începutul rândului sau după un spațiu. /* … */ pe rânduri separate e tot un comentariu.

Blocarea tastaturii tale

block { } blochează tastaturile tale cât rulează. Tastele tale nu se amestecă cu tastele macro-ului. La capătul blocului, tastaturile tale merg din nou.

Un bloc trebuie să se termine repede. De aceea sunt greșeli în block { }: while, loop, goto, o etichetă, break, continue, return, alt block și un wait() mai lung de 10000 ms. Pune bucla în afară și folosește un bloc pentru fiecare trecere.

Mouse-ul tău merge și în interiorul unui block.

Oprirea unui macro

Un macro se oprește oricând, și într-o buclă fără capăt. Patru drumuri îl opresc:

  1. butonul „■ Stop” din bara panoului
  2. „Stop macro” din meniul iconiței din tavă
  3. tasta globală „Stop macro”, implicit Pause. O schimbi pe pagina „Keys”
  4. tasta globală a macro-ului care rulează, apăsată a doua oară

În block { } merg numai primele două, fiindcă tastatura ta e blocată. Când un macro se oprește, el eliberează tastele ținute de keydown() și deblochează tastatura ta.

Mouse-ul

Coordonatele sunt ale desktopului, în unitățile lui KDE, de la colțul din stânga sus al primului ecran. AutoHotkey numără de la fereastra activă. Aici numărătoarea pornește de la desktop. Cu două ecrane, programul a fost probat numai pe unul. Un punct în afara ecranului oprește macro-ul.

KDE trebuie să dea mouse-ul programului. Dacă KDE a dat numai tastatura, o comandă de mouse oprește macro-ul, iar bara de stare a panoului arată motivul.

După actualizarea la 0.7.0, KDE cere încă o dată accesul, fiindcă programul cere acum și mouse-ul. Acceptă fereastra.

Greșelile

Sub script, un rând arată „✓ No errors” sau prima greșeală, cu rândul și coloana ei. Rândul greșelii are o linie ondulată sub el. „Save” păstrează și un script cu greșeală, ca să nu pierzi munca. Macro-ul rămâne gri până îl repari.

O greșeală cât rulează macro-ul, de pildă o împărțire la zero, oprește macro-ul. Rândul de stare al panoului arată motivul.

Ce nu e în versiunea asta

Funcțiile tale, listele, WinActivate, KeyWait, ImageSearch, MsgBox și tastele globale scrise în script nu sunt în limbaj.
